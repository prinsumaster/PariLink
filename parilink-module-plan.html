The honest headline for the client: "12 core modules working at launch, another handful shortly after, and a roadmap of advanced modules in Phase 2."  The dates above hold only if each fixed screen passes the screenshot check — a screen isn't "done" because the tool says so, it's done when the screenshot proves it.
