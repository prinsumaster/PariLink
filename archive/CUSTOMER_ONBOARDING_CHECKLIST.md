# PariLink 2.0 — Customer Onboarding Checklist

**For Customer Success Teams**

Use this checklist when onboarding a new transport company onto PariLink 2.0.

---

## Pre-Onboarding (Internal)
- [ ] Sign contract and confirm subscription tier.
- [ ] Create tenant account in Super Admin Console.
- [ ] Assign correct Subscription Plan.
- [ ] Add temporary Capacity Boost if customer requires historic data migration (e.g., 500 extra trucks for 14 days).

## Kickoff Call
- [ ] Welcome email sent with login credentials.
- [ ] Guide customer through the 10-step Onboarding Wizard:
  - [ ] 1. Company Profile & Tax Details
  - [ ] 2. Branch Locations Setup
  - [ ] 3. Invite Admin Users
  - [ ] 4. Driver Profile Creation
  - [ ] 5. Fleet / Vehicle Addition
  - [ ] 6. Customer Master setup
  - [ ] 7. Vendor Master setup
  - [ ] 8. Finance / Bank Integration
  - [ ] 9. GPS Integration Setup
  - [ ] 10. Activation
- [ ] Walk through the Dashboard and License Usage Banner.

## Data Migration
- [ ] Assist with bulk import of historic trips (if applicable).
- [ ] Verify FASTag API integration is active for the fleet.
- [ ] Verify GPS mapping is accurate.

## Training
- [ ] Conduct Dispatcher training (Command Center, Trip creation).
- [ ] Conduct Driver App training (POD upload, expenses).
- [ ] Conduct Finance training (Invoicing, ledger reconciliation).

## Post-Onboarding
- [ ] Remove temporary Capacity Boost (if applied).
- [ ] Schedule 14-day check-in call.
- [ ] Enable automated billing in Stripe.
