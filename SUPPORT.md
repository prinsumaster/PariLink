# PariLink Enterprise Support Guidelines

Welcome to the PariLink Enterprise Support portal. We are committed to ensuring your logistics operations run smoothly and securely 24/7.

## Support Channels

### 1. Enterprise Support Portal (Tier 1)
For standard bug reports, configuration questions, and user management help.
- **Portal**: `https://support.parilink.test`
- **Response Time**: < 4 hours (Business Days)

### 2. Emergency Operations Hotline (Tier 2)
For critical production incidents (e.g., API downtime, Database locks, Dispatch engine halting).
- **Phone**: Provided during onboarding in your SLA contract.
- **Response Time**: < 15 minutes (24/7/365)

## Service Level Agreements (SLAs)

PariLink Cloud Enterprise Guarantees:
- **99.99% Uptime** for Core API and Dispatch Modules.
- **Daily Automated Backups** with 30-day retention and Point-in-Time Recovery (PITR).
- **Isolated Tenant Schemas** guaranteeing data privacy.

## Disaster Recovery
For Self-Hosted (On-Premises) customers, please refer to the `Disaster Recovery Guide` located within your initial onboarding packet to set up active-passive PostgreSQL replication and MinIO syncing.
